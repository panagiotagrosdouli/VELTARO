# VELTARO — Same-day release controls
This checklist distinguishes GitHub deliverables from real-world actions; a checked code item never means a company has been formed.

## Safe repository tasks
- [x] Write founder-owned startup positioning and a one-page concept-stage pitch (this branch).
- [x] Preserve accurate stage and clear distinction between V1/R&D and potential LABS service.
- [ ] Merge PR after review and successful CI.
- [ ] Confirm Pages deployment matches reviewed main.
- [ ] Perform manual mobile/keyboard/browser checks.
- [ ] Verify both forms with harmless test submissions; see `docs/Contact-Delivery-Activation-Checklist.md`.

## Account, legal, market and safety gates — **not completed by repository changes**
- [ ] Founder confirms priorities, legal name, ownership and intended jurisdiction.
- [ ] Trademark/brand/IP rights and visual asset licenses reviewed.
- [ ] GDPR notice, data controller, processing, retention and FormSubmit transfers reviewed.
- [ ] Licensed accountant/lawyer confirm registration, tax and invoice requirements.
- [ ] Founder activates recipient inbox and verifies live message delivery.
- [ ] Independent qualified aerospace/automotive/regulatory experts review V1 research before physical work.
- [ ] Actual customers interviewed; dated evidence kept with consent.
- [ ] Contracts, pricing, delivery qualifications and a pilot established before claiming commercialization.

**Release decision:** DO NOT claim 'startup incorporated', 'service operational', 'vehicle ready', or 'investor-ready' solely because these docs are committed.
