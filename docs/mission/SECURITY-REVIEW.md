# Security and privacy review boundary
13 November 2026. New public browser tools do not use external AI services, new accounts, payment processing, cookies or server-side client records. Existing public forms and externally hosted imagery remain unchanged services with unresolved privacy/rights/delivery gates. No form was submitted by these tests.

New evidence rendering uses textContent; HTML in a LABS finding was verified to remain text in browser tests. Local LABS session is memory-only; refresh/erase removes state and exports remain owner-controlled files. No authenticated multi-user project system is implemented. The Python robot service binds loopback and rejects cross-origin browser POST requests; this is a trusted local research process, not an internet production service or a physical safety system. No secret was added or printed in repository artifacts.

Automated source checks cover references, duplicate IDs, basic language/alt/title semantics, SVG XML and engineering JSON. Existing model tests protect evidence gates. Automated axe checks are not accessibility certification. No penetration test, dependency vulnerability attestation, image-license verification, GDPR compliance determination or physical security validation is claimed. Hosted APIs, authentication, authorization, persistent client data, retention, abuse controls and operational incident procedures need a separate design before commercial deployment.
