# Content, compliance and website launch checklist

## Current scope
Static website with concept overview and independent pages for V1, Vision, Technology, Roadmap, Investors. No account system, online reservation checkout or registered lead database.

## Before launch
- [ ] Confirm **VELTARO** trademark and domain availability with competent professional advice.
- [ ] Review rights to external images, SVGs, fonts and promotional artwork.
- [ ] Replace placeholders with verified founder identity, contact information and company legal details where appropriate.
- [ ] Arrange professional review of safety, technical and financial statements.
- [ ] Decide whether inquiries should be public GitHub Issues or private email/contact system; avoid publishing confidential information in public Issues.
- [ ] If collecting emails, implement secure server storage, consent, privacy notice, retention and deletion process, abuse protection and delivery testing.
- [ ] Complete keyboard, screen-reader, mobile and reduced-motion testing.
- [ ] Validate all static links and deploy via GitHub Pages or preferred static host.
- [ ] Add automated HTML/link checks in CI before merging major site changes.

## Editorial policy
Keep conceptual status visible. Never fabricate specifications, test results, investment claims, certification, reservations or quotes. State data sources and as-of dates for market statistics.
