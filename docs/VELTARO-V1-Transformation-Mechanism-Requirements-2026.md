# VELTARO V1 — Road/air configuration requirements, Rev A
**19 October 2026 | Functional research only — no engineering drawing or qualified load case**

## Competing architecture branches
- **Branch A:** VTOL concept; examine flight-propulsion protection, ground safety, geometry and any necessary reconfiguration.
- **Branch B:** Folding fixed-wing concept; examine wing-fold envelope, positive mechanical retention, fatigue and inspectability.

No mechanism has been selected or proven feasible.

## High-level configuration model
Parked → road permitted → authorized-site assessment → conversion assessment → flight readiness review → qualified flight operation → secured landing → road configuration verification.

Every transition requires later engineering definition of legitimate conditions and safe fallback. This is **not an executable control logic design**.

## Stop conditions
If the road envelope and load-bearing flight structure conflict, or a jammed mechanism could create an unmanageable hazard, halt conceptual progression until competent review. No mockup is a safe test article by default.
