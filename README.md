# VELTARO AUTOMOBILI

A bilingual (English and Greek), responsive concept-stage corporate website for VELTARO V1, a proposed luxury road-and-air mobility vehicle.

## Preview

Open `index.html` in a browser. No npm dependencies, build commands, server, or credentials required.

## Publish with GitHub Pages

Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. If repository visibility or plan does not support GitHub Pages, use static hosting such as Netlify or Vercel.

## Included

Vision, vehicle concept, engineering challenges, safety and certification, 8-stage roadmap, business hypotheses, investors, founder manifesto, FAQ, and an EN/EL language toggle.

**Important:** All vehicle materials are conceptual. The photo backgrounds are visual references from Unsplash rather than VELTARO prototypes. The contact form deliberately does **not** send or store personal data. Before public launch, obtain permission/licensing review for imagery, domain and trademark clearance, accessibility testing, legal/privacy review, and a proper contact backend.
